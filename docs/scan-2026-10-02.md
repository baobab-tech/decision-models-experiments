# Decision-model scan, 2026-10-02

A scan of Hugging Face and the web for decision models released or updated since the 2026-09-30 survey.

## Method

- Hugging Face API `GET /api/models?search=<term>`, sorted by downloads, likes and creation date, 200 results per sort, for the terms `jev`, `systemone`, `system-one`, `system_one`, `decide`, `decision`, `noul`, `typed-decision`, `rlcd`, `decider`, `kev`. Plus author queries for `perplexity-ai`, `Cloudflare`, `StrandsAgents`, `internlm`, `autotrust`, `Mapika` and others, and searches for `clef` and `cygnet`.
- 1,437 unique repos matched; 811 were created on or after 2026-09-01. Some matches are unrelated (search is substring-based).
- Downloads are the HF API's rolling 30-day count; repos without a root `config.json` report 0, so likes are the better signal for those (Laya, Strands Decider).
- Web: news searches and vendor blogs for launches on 2026-09-30 to 2026-10-02.

## Findings

- **Two big vendors ship open weights and an API on the same day.** Cloudflare (Clef) and Perplexity (pplx-decider) both released Apache-2.0 weights with a hosted endpoint on 2026-10-01.
- **pplx-decider-v1-27b and AutoJev-27B are one model.** Every weight, config and tokenizer file has the same hash; count it once.
- **Three vendors now claim a Decision Index 0.2.1 score above Jev's 57.91 from their own runs:** GLiDE 64.81, GEV-26B-Decide 62.48 (with thinking), Clef 61.21. None is on the public board, where 0.2.1 submissions are paused.
- **Prices per 1M input tokens span 7.5×:** pplx-decider $0.04, Jev $0.042, Clef-flash $0.09, Clef $0.24, GLiDE $0.30.
- **Download counts and quality diverge.** The two most-downloaded repos (decider-2b, JEV-27B-VL) score 28.97 on DI (decider-2b) or have no board row (JEV-27B-VL). Von (80,938 downloads) and openJev Verdict (28,516) score 0.0 on JevBench.
- **JevBench v1.5.5** (109 rows) is live; Cygnet stays #1 at 73.7.
